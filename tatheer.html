A redesigned landing page, advertiser dashboard, and the design system tying them together. Six inconsistent surfaces, turned into one coherent product.

Project Summary
Overview

Landing page, dashboard, and influencer tools — each built separately over years, and it showed.

Problem

Six surfaces, six visual languages. A dated landing page lost advertisers before they ever reached the dashboard.

Goals

A landing page that converts, a modern dashboard, and a design system the team actually adopts.

My Role

Owned the landing page and design system end-to-end; partnered on dashboard and influencer UX.

Process

Auditing before designing anything new.

Two weeks auditing every button, card, and table across six surfaces — before designing anything new.

  • 140+ existing patterns catalogued down to 30 core components.

  • Landing page tested against five sequential variants.

  • Paired with engineers so code and Figma shipped together.

  • Ran an adoption workshop instead of just shipping docs.

Design System

Thirty components, one source of truth.

One type scale, an 8px grid, one color system — a brand update now touches one file, not six.

UX Decisions

Small calls that added up.

  • Hero leads with one outcome, not a feature list.

  • Dashboard tables share one row and filter pattern.

  • Component usage guidance lives right in Figma.

  • Onboarding cut from seven screens to three.

Challenges

Getting a team to actually adopt a system.

Three squads, three sets of component habits — a system only works if people use it. New features required the system; legacy screens migrated gradually, so it had to earn adoption, not mandate it.
